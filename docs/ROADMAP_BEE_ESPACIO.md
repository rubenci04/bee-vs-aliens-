# Bee héroe — evolución para el Nivel 7 (Espacio)

El Bee v02 deja el ancla `helmet_socket` libre para una escafandra futura. El casco debe ser una pieza modular separada que se acople a esa toma, con visor transparente y proporciones que mantengan visible la expresión de la cara. No se modela ni se integra en el lote actual.

Para el Nivel 7, desarrollar un set espacial intercambiable por nivel: casco y traje reconocibles sobre la silueta amarilla del Bee, placas y uniones reutilizables, y refuerzos de los dos propulsores para maniobras en vacío. Las llamas de propulsión se resuelven con efectos cálidos de juego; reservar el cian/violeta para tecnología hostil. El socket y los puntos de montaje deben permitir equipar o retirar las piezas sin alterar el origen ni la animación de vuelo del héroe.

Destino de arte: `assets/models/levels/level_07_space/` y `art_source/blender/levels/level_07_space/`; conservar los nodos del héroe como base compartida y probar el atuendo en una escena de laboratorio antes de integrar al jugador.
